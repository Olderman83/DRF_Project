## Описание проекта

LMS (Learning Management System) - образовательная платформа для управления курсами, уроками и платежами.

### Основные функции

- Управление курсами и уроками
- Аутентификация и авторизация пользователей (JWT)
- Уведомления об обновлении курсов (Celery)
- Интеграция с платежной системой Stripe
- Пагинация и фильтрация данных
- Swagger/ReDoc документация API
- Полная контейнеризация с Docker

## Требования

- Docker (версия 20.10+)
- Docker Compose (версия 2.0+)
